ACCESSIBLE BY DESIGN

Make information easier for more people to use

Healthcare navigation information is useful only when people can perceive it, understand it and use the available controls.

Readable content

Use plain language, descriptive headings, short paragraphs and clearly labelled links so visitors can find relevant information without needing specialist knowledge.

Keyboard navigation

Interactive elements should be reachable and usable with a keyboard, with visible focus indicators and a sensible navigation order.

Mobile and zoom support

Pages should reflow across screen sizes, preserve readable text when zoomed and avoid requiring horizontal scrolling for ordinary content.

Meaningful images and labels

Informative images should have useful alternative text; decorative images should not create unnecessary noise for screen-reader users.

Colour and contrast

Colour should not be the only way information is communicated. Text, controls and focus states should maintain appropriate contrast.

Feedback and improvement

If a page or interaction creates a barrier, use the accessibility feedback route so the issue can be understood and prioritised.
